# Charlie's Crew Board

Staff and volunteer app for Gladstone Backpackers: today's jobs, what's coming up, promo reels, handover notes and the scoreboard.

- Live at https://totalwelding.github.io/charlies-crew-board/
- Sign-in: Google. New crew sign in, then a manager lets them in under **Job list → Crew access**.
- Data: Firebase project `charlies-crew-board` (Firestore, Sydney). Security rules are in `firestore.rules`.
- Reels live in `reels/`.
